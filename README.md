## Entry

> My dad told me never to make a big decision when you're tired, angry, or
> hungry, and twenty years later I still check all three before I answer.

## How it works

`main.py` (Python 3 standard library only) writes the sentence to
`/output/entry.txt`, asserting it is a single line of 1–200 characters.
